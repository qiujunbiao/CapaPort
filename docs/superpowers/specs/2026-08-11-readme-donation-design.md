# README 打赏区设计

## 目标

在公开仓库 README 中增加一个克制、清晰的项目支持入口，同时确保支付宝和微信收款码不依赖临时文件路径，在 GitHub 页面中长期可见。

## 页面位置与文案

- 在 README 的“参与项目”和“许可”之间新增二级标题“支持项目”。
- 引导文案为：“如果 CapaPort 对你有帮助，可以请作者喝杯咖啡。感谢你的支持，这会帮助项目持续维护和迭代。”
- 不增加赞助等级、承诺回报、外部跳转或金额说明。

## 图片资源

- 支付宝图片保存为 `docs/assets/donate/alipay.jpg`。
- 微信图片保存为 `docs/assets/donate/wechat-pay.jpg`。
- 使用用户提供的原始图片，不裁剪、不重绘二维码，避免影响识别。
- 两张图片随公开仓库发布，属于明确公开内容。

## README 布局

使用 GitHub Markdown 支持的 HTML 表格并排展示：

- 两列标题分别为“支付宝”和“微信支付”；
- 每张图片宽度设置为 `280`，保留原始宽高比例；
- 小屏幕由 GitHub 页面按表格规则展示，不增加额外 CSS 或脚本；
- 图片使用仓库相对路径，保证 fork、镜像与离线浏览仍可解析。

## 验证

- 确认两张仓库图片存在、格式为 JPEG，且尺寸与用户提供的原图一致；
- 检查 README 中的相对路径能够解析到对应文件；
- 运行 Markdown/格式检查和 `git diff --check`；
- 确认除 README、两张图片和本设计相关交付文件外没有其他改动。
