# CapaPort 威胁模型

## 范围与资产

保护对象包括账号与会话、组织成员和角色、私有能力包、项目上下文、对象存储制品、签名密钥、审计记录、本地授权目录和安装锁。业务源码与设备绝对路径不属于云端数据模型，除非用户违反产品边界主动写入能力包；客户端与服务端扫描必须阻止此类内容。

## 信任边界

1. Desktop/CLI/Web 到 API：客户端和请求参数均不可信，API 必须重新执行身份、租户、空间和资源授权。
2. API 到 PostgreSQL/Redis/S3：内部服务只通过私网和独立凭据访问，数据库记录与对象摘要共同校验制品身份。
3. Desktop 到本地文件系统：只有用户明确授权的根目录可写，规范化路径后拒绝穿越、符号链接和根目录逃逸。
4. CI 到签名与发布平台：签名私钥只存在于受保护环境，产物必须具备摘要、SBOM、来源证明和平台签名。
5. 组织之间：组织 ID 是所有受保护查询、对象键和队列任务的强制隔离条件。

## 主要威胁与控制

| 威胁 | 受影响主体 | 主要控制 | 剩余风险/运营要求 |
| --- | --- | --- | --- |
| 凭据填充、会话窃取 | 用户、组织 | 强密码哈希、验证码限流、短期访问令牌、刷新轮换、设备会话撤销 | 生产接入异常登录告警和 MFA/SSO |
| IDOR/跨租户读取 | 组织数据 | 服务端租户上下文、空间授权、对象键隔离、统一拒绝响应、租户测试矩阵 | 新接口必须进入资源矩阵测试 |
| 能力包携带密钥或源码 | 能力所有者、组织 | 客户端预扫、服务端权威扫描、阻断级别不可绕过、显式文件选择、源码扩展名拒绝 | 规则库需持续更新并处理误报申诉 |
| Zip Slip、路径穿越、符号链接 | 终端设备 | 归一化相对路径、解压边界、授权根校验、符号链接拒绝 | 新适配器必须通过 SDK 合规测试 |
| 本地文件被静默覆盖 | 终端用户 | 安装预览、摘要锁、冲突选择、暂存/备份/原子提交/回滚 | 用户保留的本地文件不纳入托管锁 |
| 恶意或不兼容能力包 | 终端用户 | Manifest schema、Agent×组件兼容矩阵、摘要校验、原生格式投影、发布审核 | 新 Agent/组件加入前更新矩阵和夹具 |
| 未签名或降级更新 | 全部桌面用户 | Tauri updater 公钥、HTTPS、平台签名、公证/时间戳、受保护发布环境 | 首发前必须替换开发公钥并完成真机升级/回滚演练 |
| 审计记录篡改 | 管理员、审计人员 | 追加写入、角色限制、租户隔离、关键操作全量记录 | 生产应导出到不可变日志存储并设置保留期 |
| 队列重放或重复提交 | 云端状态 | 幂等键、状态机约束、重试上限、死信队列 | 监控重复率和永久失败任务 |
| 对象存储泄露 | 能力包与上下文 | 私有桶、短时签名 URL、服务端加密、摘要确认、最小权限 IAM | 配置访问日志、生命周期和密钥轮换 |

## Agent 原生投影边界

- Codex 项目上下文写入项目根 `AGENTS.md` 的 CapaPort 托管区块。
- Claude Code 写入 `.claude/rules/capaport/**/*.md`。
- Cursor 写入 `.cursor/rules/capaport/**/*.mdc`，带 `alwaysApply` 元数据。
- Gemini CLI 项目上下文写入项目根 `GEMINI.md` 的 CapaPort 托管区块；自定义命令写入 `.gemini/commands/*.toml`。

共享入口文件保留 CapaPort 标记区块之外的用户内容。投影计划记录当前摘要，预览到提交之间发生变化时必须冲突失败；多 Agent 同步任一步失败时回滚本批次已经应用的本地事务。

## 安全假设与不覆盖项

- 已被终端管理员完全控制的设备无法由应用自身恢复可信状态。
- 组织管理员有权读取组织空间内已授权共享的能力包，但无权读取其他组织数据。
- CapaPort 不执行能力包中的任意脚本；若未来开放执行器，必须新增沙箱、网络出口和供应链威胁模型。
- 外部 SMTP、SMS、S3、数据库、GitHub 和证书机构的可用性与账号安全由部署方共同承担。

## 复核触发条件

新增 Agent 适配器、执行器、跨组织共享、企业 SSO/SCIM、私有化部署、外部插件 SDK 或安全事件后，必须重新评审本模型并扩展自动化门禁。
