# 桌面端与本地适配器

桌面端面向 macOS 与 Windows。功能遵循“桌面端能力大于等于 Web 管理后台”的原则：除账号登录、本地 Agent 发现、能力库、创作、项目绑定、安装、更新与冲突恢复外，也提供完整的组织治理能力。

## 组织治理

桌面端按当前组织角色显示治理入口：

- 所有成员可查看组织概览、能力资产和组织信息。
- Owner 与 Admin 可查看安全扫描和版本差异后审核发布，并管理能力版本、成员邀请、空间策略与安全策略。
- Auditor 可查看安全中心、不可变审计日志和采用分析，但不能执行管理写操作。
- Owner 可导出组织数据、移交所有权和管理组织关闭；用户可导出账号数据并管理账号注销。

未审核能力不会进入可安装能力库；只有存在已发布版本的能力才允许生成安装计划。审核按钮只有在候选摘要、安全扫描与版本差异全部加载成功后才可用。

## 支持目录

适配器通过 Agent 的用户级目录和项目级目录发现内容：

- Codex：共享 `.agents/skills`、全局 `.codex/skills`、已安装插件包中的 `skills` 目录，以及已绑定项目的 `.agents/skills`。
- Claude Code：用户/项目 `.claude`。
- Cursor：项目 `.cursor`。
- Gemini CLI：用户/项目 `.gemini`。
- WorkBuddy：用户级 `~/.workbuddy/skills`，项目级 `.codebuddy/skills`。
- 千问 Work（QwenWork）：用户级 `~/.qwenworkcn/skills`，不提供项目级目录。

实际目录由本机适配器探测结果决定，界面会展示作用域和路径。项目空间可绑定多个本地项目目录，每个绑定单独选择同步规则、上下文和能力包。

Skill 发现会递归查找包含 `SKILL.md` 的能力目录，并按规范化后的真实路径去重。从上述可信 Skill 根目录直接进入的目录符号链接可以指向用户目录内外；断链、循环链接或无权限目录会被单独跳过，不影响其他能力。能力包确定后，其内部链接只能解析到同一能力包目录内。

WorkBuddy 与千问 Work 当前只支持 Skill。安装和导入会完整保留 `SKILL.md`、`scripts/`、`references/` 与 `assets/` 等普通文件；Prompt 和项目上下文不会被转换为 Skill。

## 安全边界

- Tauri 安装命令仅接受已授权写入根目录内的规范化路径；发现到的外部链接目标只获得扫描和导出的只读权限，不会成为安装写入根。
- 路径策略拒绝 `..`、能力包内部符号链接逃逸和未授权绝对路径。
- 安装先生成计划并验证，再通过临时文件和重命名提交；失败会回滚。
- 凭据进入系统钥匙串；本地索引使用 SQLite，不存储云端明文密码。
- 默认只读取已知 Agent 配置，不扫描或上传项目源码。

## 离线与恢复

离线时可查看本地清单和安装记录；发布、搜索和下载需要联网。网络恢复后重新同步。若安装中断，再次打开时会识别未完成事务并恢复上次稳定状态。
