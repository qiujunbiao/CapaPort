# 桌面端与本地适配器

桌面端面向 macOS 与 Windows，提供账号登录、组织引导、本地 Agent 发现、能力库、发布、项目绑定、安装更新和设置页。

## 支持目录

适配器通过 Agent 的用户级目录和项目级目录发现内容：

- Codex：用户/项目 `.agents` 与兼容 Skill 目录。
- Claude Code：用户/项目 `.claude`。
- Cursor：项目 `.cursor`。
- Gemini CLI：用户/项目 `.gemini`。

实际目录由本机适配器探测结果决定，界面会展示作用域和路径。项目空间可绑定多个本地项目目录，每个绑定单独选择同步规则、上下文和能力包。

## 安全边界

- Tauri 命令仅接受已授权根目录内的规范化路径，拒绝 `..`、符号链接逃逸和未授权绝对路径。
- 安装先生成计划并验证，再通过临时文件和重命名提交；失败会回滚。
- 凭据进入系统钥匙串；本地索引使用 SQLite，不存储云端明文密码。
- 默认只读取已知 Agent 配置，不扫描或上传项目源码。

## 离线与恢复

离线时可查看本地清单和安装记录；发布、搜索和下载需要联网。网络恢复后重新同步。若安装中断，再次打开时会识别未完成事务并恢复上次稳定状态。
