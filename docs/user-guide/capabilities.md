# 能力包、版本与更新

一个能力包可同时包含：

- Skill：Agent 可执行的说明和辅助文件。
- Prompt：可复用的任务提示模板。
- Context：架构约束、术语、协作规则等项目知识；默认不包含业务源码。

根目录 `agentdoor.yaml` 描述元数据、组件路径、兼容 Agent 和入口。每个发布版本绑定不可变制品与 SHA-256 内容摘要；同一版本号不能替换内容。

## 生命周期

`草稿 → 提交 → 扫描 → 审核 → 发布 → 下载 → 安装 → 更新`

个人草稿可自由编辑。团队/项目空间是否审核由空间策略决定；组织空间必须审核。被驳回的提交保留原因，可从原草稿修订后重新提交。

## 更新与本地修改

安装锁文件保存每个已安装文件的摘要。更新时：

- 当前文件仍等于上次安装摘要：允许安全更新。
- 当前文件被本地修改：禁止静默覆盖，并显示云端/本地差异。

冲突时可选择保留本地文件、把本地版本导入为新个人草稿，或恢复上次已安装版本后更新。所有选择均写入审计记录。

## 敏感信息

上传前和服务端发布前都会扫描密钥、令牌、私钥、连接串和疑似高熵秘密。报告只保存规则、文件位置和证据摘要，不回显秘密原文。
