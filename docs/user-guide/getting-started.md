# 用户快速开始

## 注册与加入组织

1. 在桌面端或 Web 后台选择邮箱或手机号注册，设置密码并输入验证码。
2. 首位用户可创建组织；收到邀请的用户从邮件/短信链接进入并登录后接受邀请。
3. 在当前组织菜单切换组织。个人空间始终归当前账号；组织、团队、项目空间按成员关系可见。

开发环境的验证码在 <http://127.0.0.1:8025> 查看。生产环境必须连接受控 SMTP/短信供应商。

## 第一次沉淀能力

1. 在桌面端“本地发现”中选择项目目录并运行扫描。
2. 查看 Codex、Claude Code、Cursor、Gemini CLI、WorkBuddy 或千问 Work 中发现的原生能力。
3. 选择条目，补充名称、说明、标签、目标 Agent；需要时加入不含源码的项目上下文文档。
4. 客户端先执行敏感信息扫描。阻断项必须删除；仅在组织策略允许时确认非阻断警告。
5. 保存到个人空间，或提交到团队/项目/组织空间。
6. 需要审核时等待负责人查看版本差异和扫描报告。组织空间发布始终需要审核。

## 第一次安装

在能力库按名称、标签、兼容 Agent 搜索，选择已发布版本和本地 Agent。安装前会显示写入文件、目标目录和覆盖风险；确认后原子写入并记录锁文件。安装状态会同步到云端，业务源码不会上传。

## 权限不符合预期

个人空间只有本人可见。团队/项目空间要求显式成员关系，组织空间要求组织成员关系。发布、审核、成员管理、审计分别受角色限制；管理员也不能跨组织查询资源。
