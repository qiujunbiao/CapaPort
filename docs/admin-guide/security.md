# 安全基线

## 身份与租户

- 新密码至少 8 个字符，可使用字母、数字和符号，不强制混合字符类型；本地强度评估会拒绝明显简单、容易猜测或包含账号信息的密码。
- 注册和找回密码会使用 Google Password Defense 私密检查已泄露凭据；供应商不可用时安全失败并允许用户稍后用同一验证码重试。密码采用强哈希，验证码、刷新令牌和邀请令牌只保存不可逆摘要。
- 访问令牌短时有效，刷新令牌轮换并支持撤销；设备会话可单独注销。
- 每个受保护查询强制绑定当前组织和空间成员关系。无权限资源统一返回拒绝/不存在，不泄露名称、slug 或版本。
- 审计日志追加写入，禁止普通成员修改。

## 能力包与本地文件

- 客户端上传前扫描，服务端发布前再次扫描；阻断秘密不能靠客户端确认绕过。
- 对象通过短时签名 URL 传输，数据库只存元数据和摘要。
- 桌面端路径先规范化，并验证仍位于用户授权根目录；拒绝符号链接逃逸和路径穿越。
- 安装采用计划、校验、临时写入、原子提交和回滚；检测本地改动后禁止静默覆盖。

## 容器与网络

API、Worker、Migrate 使用固定 UID/GID `10001:10001`，只读根文件系统、全部 capability 丢弃、`no-new-privileges` 和受限临时目录。秘密通过文件挂载。数据库、Redis 和内部对象端点不应直接暴露公网。

## 运营要求

- 在正式启用前更换 Tauri updater 公钥和所有开发凭据。
- 为 GitHub Actions 配置受保护环境和最小权限签名秘密。
- 定期运行 `pnpm security:gate`、镜像漏洞扫描和依赖更新评估。
- 发现疑似泄露时先撤销真实凭据，再隔离制品和会话；不要只删除扫描报告。
