# 分级治理与审核

个人空间允许成员自由保存和迭代。团队/项目负责人可配置直接发布或必须审核；组织空间始终进入审核队列，不允许关闭。

审核人检查：

1. 能力包名称、说明、标签、兼容 Agent 和目标空间。
2. 相对上一版本的新增、修改、删除文件。
3. 客户端和服务端扫描结果；阻断项不能批准。
4. 上下文是否只包含必要组织知识，不含源码、个人信息或生产配置。
5. 版本号是否符合语义化版本约定。

批准后发布版本和内容摘要不可变。更新必须创建新草稿和新版本。审核人不能批准自己无权访问的空间；所有提交、批准、驳回、发布、下载、安装、更新都记录操作者、组织、资源、请求关联号和时间。

建议至少分离“贡献者”和“审核人”；高风险组织可要求团队负责人以外的组织审核人批准。
